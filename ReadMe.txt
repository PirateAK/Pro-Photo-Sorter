========================================================================
              PRO PHOTO SORTER — READ ME FIRST
                      Version 1.3.1
========================================================================

Thanks for grabbing Pro Photo Sorter. This is a fully offline Windows
desktop app for photographers who shoot faster than they file — no
cloud, no subscription, no accounts. Your photos never leave your
machine.


------------------------------------------------------------------------
  QUICK INSTALL  (3 steps, about 1 minute)
------------------------------------------------------------------------

  1. Double-click:
        Pro Photo Sorter Setup 1.3.1.exe

  2. If Windows shows a blue "SmartScreen" warning, click
        "More info" -> "Run anyway"
     This is normal for indie apps that aren't Microsoft-signed. The
     software is safe. (Every real photographer's tool started here.)

  3. Click through the installer. When it finishes, Pro Photo Sorter
     opens automatically. That's it.

  The installer places the app in:
        C:\Users\<You>\AppData\Local\Programs\Pro Photo Sorter\
  A desktop shortcut and a Start-Menu entry are created for you.


------------------------------------------------------------------------
  FIRST LAUNCH  (2 minutes to a sorted photo)
------------------------------------------------------------------------

  1. Click "Load Source" at the top-left, then pick a folder full of
     photos. Your images appear in the filmstrip at the bottom.

  2. Click any photo to see it in the big viewer. Use the arrow keys
     (or the arrow buttons under the viewer) to move through.

  3. Open the Tag Manager and pick a Category, then a Sub-folder,
     then click filename tags to build a destination path like:
        Wildlife / Bears / Grizzly / Alaska_Trip
     Photos are stored with their tags applied — original files are
     never overwritten.


------------------------------------------------------------------------
  TRIAL vs FULL LICENSE
------------------------------------------------------------------------

  Right out of the box you're in TRIAL MODE. It works the same as the
  full version, with ONE small difference:
     -> Every file you store gets "_TRIAL" appended to its filename.

  When you're ready to remove the suffix, buy your license key from:

        https://gumroad.com/  (search "Pro Photo Sorter")

  Then in the app: click "Help" -> "License" tab -> paste your key ->
  "Activate". One-time purchase, lifetime license.

------------------------------------------------------------------------
  WHAT'S NEW IN v1.3.1
------------------------------------------------------------------------

  * CUSTOM IMAGES LIBRARY — right-rail toolbox in Tag Manager with
    Basic Icons (60+ built-ins) plus your own PNGs. Bulk-import,
    drag onto any chip, share as .pps-iconpack.json files.

  * SIX FREE STARTER ICON PACKS — Wildlife, Wedding, Sports, Holiday,
    Family Portrait, Nature/Landscape. One click to install.

  * CONTACT SHEET PREVIEW — see the PDF before you save it. Adjust
    columns or page size and regenerate, or save with one click.

  * CROSS-CATEGORY CHIP DRAG — drag any filename tag onto another
    category in the left rail to move it. Ctrl+drag to copy.

  * "DELETE EMPTY (N)" cleanup button in every category header.

  * SAFETY-BACKUP restore button in Settings — one-click recovery of
    your entire tag library from the automatic mirror in Documents.

  Plus a dozen quality-of-life fixes. See User Guide for full details.


------------------------------------------------------------------------
  BACKUP & PORTABILITY
------------------------------------------------------------------------

  Pro Photo Sorter automatically mirrors your tags, categories, and
  license to a safety backup file at:

        C:\Users\<You>\Documents\Pro Photo Sorter\Safety-Backups\
        latest.json

  If you ever need to move to a new machine: install the app there,
  copy that "latest.json" file into the same folder on the new
  machine, launch — everything comes back automatically.
