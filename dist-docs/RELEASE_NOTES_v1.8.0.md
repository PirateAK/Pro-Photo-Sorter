# Pro Photo Sorter v1.8.0 + Tag Pack Creator v1.8.0

Two releases in one — **v1.7.0 (Tag Pack Shipper)** and **v1.8.0 (the two apps work as one)**.

## Tag Pack Shipper (v1.7.0)
- One `.pps-shipper.json` carries several tag packs, up to 3 preview images, a title, description, **author** and **link**.
- **PPS:** Tag Manager → Bundle… → **Ship…**. Import a shipper with **Import pack…** — you see a preview, then each pack runs through Merge / Replace / Create new.
- **Creator:** **Shipper…** button → Save or **Install into PPS**.
- Every pack file now carries your **link** next to **author**; both are remembered so you type them once.

## The two apps find each other (v1.8.0)
- PPS mirrors every pack to `Documents\Pro Photo Sorter\Library\`. In the Creator, **From PPS library…** lists them — open, edit, **Install into PPS**. No file dialogs.
- **Open Tag Pack Creator** in PPS's Tag Manager; **Open Pro Photo Sorter** in the Creator. If the other app isn't installed you get a **Get it** link; if it's on an older version, an **update** nudge.

## Install
Download **Pro Photo Sorter Setup 1.8.0.exe** and **Tag Pack Creator Setup 1.8.0.exe** below. Both are free to try; PPS unlocks with your Gumroad license.
Your tags, ratings and license carry over automatically.
