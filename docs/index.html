The loop

Four moves per photo. Then the next one is already loaded.

01

Open

Point the left tree at any folder — SD card, external drive, NAS. Thumbnails cache locally so the second visit is instant.

02

Tag

Drag or click tags onto the photo. Rate with 1–5. Hit R to repeat the last set on a similar shot.

03

Store

Press S. The photo lands in the right folder with the right name and an .xmp sidecar beside it.

04

Repeat

Next frame is up. Space skips, Del trashes (with undo), B batches a whole selection at once.

Every stored photo gets an Adobe-standard XMP sidecar containing your star rating and every keyword. Import the folder into Lightroom and the whole cull shows up — already rated, already tagged. Zero re-typing.

  • Stars round-trip as xmp:Rating

Questions

Things people ask before buying.

Still stuck? Email leaderteamk@gmail.com — replies may take a day if the boat's out of range.

Does it work with RAW files?

Version 1 sorts, tags and stores any file your camera writes — RAW included — but the viewer previews JPEG, PNG, WebP, GIF and BMP. Native RAW previews are the headline feature for v2. Shoot RAW+JPEG and you get the best of both today.

Does it modify my original photos?

Never. Store copies (or moves, if you choose) your file to the destination and writes a separate .xmp sidecar. Edits are always saved as new files. Deleted photos go to a .pps-trash folder with one-click undo.

Is it really offline?

Yes. The only network call is a single license check against Gumroad when you enter your key. After that it never connects. There is no account, no sync, no analytics.

What about Mac or Linux?

Windows 10/11 only for now. Mac is on the roadmap once v1 is paying for the coffee.

Can I move my tag packs to another PC?

Yes — Tag Manager has Export, Import and a one-click "Backup All" zip. The app also keeps a daily safety backup in your Documents folder so a reinstall never loses your work.
