# Pro Photo Sorter — Starter Tag Packs

These are opinionated tag packs to help you (and your clients) hit the ground running.

**How to use:**
1. Launch Pro Photo Sorter and open the **Tags** menu.
2. Click **Import pack…** on the left rail.
3. Pick one of the `.pps-tagpack.json` files from this folder.
4. The pack lands in your Tag Manager alongside your existing packs — never overwrites, never destroys.

**What's inside:**

| File | Best for |
|---|---|
| `wedding.pps-tagpack.json` | Wedding photographers — ceremony, reception, portraits, details |
| `wildlife.pps-tagpack.json` | Wildlife (Alaska-first) — species, behavior, habitat |
| `landscape.pps-tagpack.json` | Landscape work — time of day, subject, technique |
| `portrait.pps-tagpack.json` | Studio & location portraits — pose, light, setting |
| `real-estate.pps-tagpack.json` | Home listings — room-by-room, exterior, technique |
| `sports.pps-tagpack.json` | Field, court, rink — action, moments, people |

**Sharing:**
- Share any `.pps-tagpack.json` file — email, thumb drive, cloud share
- Recipient runs **Import pack…** and it's ready to use
- Custom-image icons are embedded in the file, so packs are fully self-contained

**Making your own:**
- Open **Tags** → build your pack → click **⬇ Export pack** to save it as a `.pps-tagpack.json` file
- Send it to a friend, or drop it in this folder as a personal template
